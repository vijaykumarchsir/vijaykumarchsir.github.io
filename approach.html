How I teach

Short lessons. Clear targets. Practice that looks like the real paper.

1. Find the gap

The first session is a diagnostic. We test reading, grammar and writing, then fix the weakest area first.

2. Teach the method

Every answer type has a structure. I teach the structure, show a model, then the student writes one.

3. Mark and rewrite

Feedback comes the same week. Students rewrite until the answer meets the board’s marking scheme.

4. Read widely

Set texts plus short, interesting outside reading. Vocabulary grows from use, not lists.

5. Exam rehearsal

Timed papers before every exam, so the real one feels familiar.
